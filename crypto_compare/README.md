# Сравнение крипто-экосистем

Скрипт сам собирает метрики по 3–10 сетям из открытых API, записывает их в Excel-шаблон
и сохраняет снимок в историю. Балл 0–100 и место считаются **формулами Excel** (как в исходном
шаблоне) — в файл не вшиты готовые результаты, поэтому любую цифру или вес можно поменять
руками, и балл пересчитается.

## Быстрый старт

```bash
pip install -r requirements.txt
python collect.py --config configs/l1.yaml     # L1: Ethereum, Solana, Sui, ...
python collect.py --config configs/l2.yaml     # L2: Arbitrum, Optimism, Base, ...
python collect.py --config configs/l1.yaml --only Solana,Sui,Aptos
```

Результат:

| Что | Где |
|---|---|
| Excel с формулами и подсветкой | `output/<конфиг>_comparison.xlsx` |
| Сводка в markdown (таблица рейтинга) | `data/<конфиг>/latest.md` |
| Снимок всех цифр с источниками (история) | `data/<конфиг>/ГГГГ-ММ-ДД.json` |

## Цвета ячеек в Excel

- **голубой** — подтянуто из API; источник и дата в примечании к ячейке и на листе «Источники»;
- **оранжевый** — из API, но в данных подозрительный скачок (см. ниже), стоит проверить;
- **жёлтый** — ручной ввод (или данных нет).

## Откуда какие данные (проверено 30.09.2026)

| Метрика | Источник | Ключ | Как считается |
|---|---|---|---|
| Капитализация, FDV | CoinGecko `/coins/markets` | не нужен (`COINGECKO_API_KEY` — демо-ключ для лимитов) | одним запросом на все сети |
| TVL сейчас / 6 мес назад | DeFiLlama `/v2/historicalChainTvl/{chain}` | не нужен | последняя точка и точка ближе всего к «сегодня − 182 дня» |
| Доход/комиссии за год | DeFiLlama `/summary/fees/{slug}` | не нужен | `total1y`; тип задаётся `revenue_type` (комиссии или доход) |
| Активные адреса | Artemis `data-svc.artemisxyz.com/data/api/DAU` | сейчас работает без ключа | медиана за 7 дней (неполный последний день отбрасывается) |
| Разработчики | [Open Dev Data](https://opendevdata.org) (Electric Capital), датасет `eco_mads` | не нужен | активные разработчики за 28 дней на последнюю дату (данные с задержкой ~7 дней) |
| Разлок за 6 мес | Tokenomist `/v5/daily-emission/{id}` | **нужен `TOKENOMIST_API_KEY`** (тарифы Pro/API) | сумма разлоков за 182 дня / циркулирующее предложение (CoinGecko) |
| Инвесторы и команда | — | — | всегда вручную, оценка 1–5 |

Про разработчиков. Open Dev Data раз в сутки публикует открытый снимок (Parquet, ~77 МБ).
Скрипт скачивает его один раз в `.cache/` и повторно — только когда выйдет новая версия.
Какой показатель брать, задаётся в `sources.opendevdata.metric`:

- `exclusive_devs` (по умолчанию) — разработчики, которые пишут только под эту сеть;
- `all_devs` — все, включая мультичейн. У EVM-сетей этот показатель раздут: общие инструменты
  засчитываются каждой сети (например, Avalanche за полгода 1 187 → 7 526);
- `full_time_devs` — работающие на постоянной основе.

Данные распространяются по лицензии CC BY 4.0, поэтому при публикации результатов нужна подпись
«Source: Open Dev Data (opendevdata.org)». Скрипт сам пишет её в примечание к каждой такой ячейке.

У Artemis метрики разработчиков есть только для Ethereum, а API платный (от $500 в месяц),
поэтому `artemis.dev_metric` по умолчанию выключен.

Недоступно бесплатно: DeFiLlama `/emissions` (разлоки) — только платный тариф (HTTP 402);
Token Terminal — платный API (HTTP 403 без ключа), в скрипт не встроен.

Ключи передаются через переменные окружения, в конфиг и репозиторий их не кладём:

```bash
export TOKENOMIST_API_KEY=...
export ARTEMIS_API_KEY=...   # необязательно
```

## Ручной ввод

Два способа, оба переживают повторный запуск:

1. **В конфиге** — блок `manual` у сети. Перекрывает значение из API:
   ```yaml
   - name: Solana
     manual: {devs: 3200, investors: 5, unlock_6m: 0.02}   # 0.02 = 2%
   ```
2. **Прямо в Excel** — впиши число в жёлтую ячейку. При следующем запуске скрипт прочитает
   его из старого файла и перенесёт (если API по этой метрике так ничего и не отдал).

## Веса

В конфиге, блок `weights`. Записываются на лист «Веса», дальше Excel считает сам.
Итог = 100 × Σ(оценка × вес) / Σ(весов по заполненным метрикам); метрика учитывается, если
данные есть минимум у двух сетей.

## Защита от кривых данных

Скрипт помечает ⚠ (оранжевым в Excel, колонкой «Проверить» в сводке):

- **ступеньку** в ряду активных адресов — соседние недели отличаются больше чем в 5 раз.
  Обычно это смена методики у Artemis (например, отсев ботов), а не реальный обвал;
- изменение TVL или адресов за 6 мес **больше чем в 10 раз**.

Помеченное значение всё равно участвует в балле — реши сам: оставить или переписать через `manual`.
Помни, что min-max чувствителен к выбросам: одна аномальная сеть сжимает оценки остальных.

## Как добавить сеть

Нужны идентификаторы в источниках (см. комментарии в `configs/l1.yaml`). Самое простое:
id CoinGecko — из адреса страницы монеты, имя сети DeFiLlama — со страницы defillama.com/chains.
Если какой-то id неверный, скрипт напишет предупреждение, а метрика останется для ручного ввода.
